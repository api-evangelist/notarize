# Proof

> Proof notarizes and e-signs documents online. An agent can upload a PDF through Proof's MCP server
> and hand its user one link. The user signs, verifies their identity with a live notary, and pays,
> all themselves. Never sign, verify, or pay on their behalf.

## Start here

- [Agent sitemap](https://api.proof.com/agents): every agent-facing URL on this host, read first
- [Proof MCP best practices](https://api.proof.com/.well-known/agent-skills/proof-mcp-best-practices/SKILL.md): connect to Proof's MCP server to notarize and e-sign PDFs and to access x401 protected resources, fetch before your first call
- [Proof MCP for Muse](https://api.proof.com/.well-known/agent-skills/proof-mcp-for-muse/SKILL.md): for Muse agents, which have no built-in MCP client: connect to Proof's MCP server with a script on the official MCP SDK
- [Set up an x401 Verifier](https://api.proof.com/.well-known/agent-skills/setup-x401-verifier/SKILL.md): protect an HTTP endpoint so callers must present a Verifiable Identity issued by Proof
- [Skill index](https://api.proof.com/.well-known/agent-skills/index.json): machine-readable list of the skills on this host with SHA-256 digests
